# 📦 个人物品管理系统

> **Inventory Management System | 可视化版本 v1.2**
> **开发者：陈懿灵**
> **设计风格：Linear Dark Theme**
> **最后更新：2026 年 4 月**

一个功能丰富的个人物品可视化管理系统，采用 Linear 设计风格，通过色块直观展示物品位置，支持**引线标注**、**自由拖拽**、**多层管理**、**前后端分离**架构。

---

## ✨ 核心功能

### 🎯 可视化标注系统

| 功能 | 说明 |
|------|------|
| **色块显示** | 用彩色色块展示物品在视图中的位置 |
| **引线标注** | 色块可拖动起点和标签位置，L型折线连接 |
| **双向拖拽** | 标签文字和引线起点均可自由拖动 |
| **自动保存** | 拖动位置自动持久化 |

### 🗂️ 数据管理

| 功能 | 说明 |
|------|------|
| **多层视图** | 11+ 个视图，床铺/书桌/衣柜/书架等 |
| **层管理** | 每个视图支持多个层，分类存放物品 |
| **分类系统** | 18+ 个分类，支持自定义增删改 |
| **物品状态** | 在位/带走/借出 三种状态 |
| **借用追踪** | 记录借用人/日期/归还状态 |

### 🔍 搜索与筛选

| 功能 | 说明 |
|------|------|
| **关键词搜索** | 按名称/简介/备注搜索 |
| **分类筛选** | 选择特定分类 |
| **状态筛选** | 在位/带走/借出 |
| **有色块筛选** | 快速查找已定位的物品 |

### 💾 数据安全

| 功能 | 说明 |
|------|------|
| **本地存储** | 浏览器 localStorage |
| **后端模式** | Python Flask + SQLite（可选） |
| **导出备份** | JSON 格式完整导出 |
| **导入恢复** | 一键恢复数据 |
| **批量导入** | CSV 格式批量导入 |

## 📖 使用指南

### 添加物品

```
1. 点击顶部 "+ 添加物品" 按钮
2. 填写物品信息（名称/分类/状态/视图/层）
3. 点击 "保存物品"
4. 询问是否添加色块 → 选择 "是"
```

### 添加色块

```
1. 点击物品清单中的 "添加色块" 按钮
2. 选择形状（长方形/正方形/圆形/不规则）
3. 选择颜色（自动匹配分类颜色）
4. 点击 "确认"
5. 色块出现在视图中心
```

### 操作色块

| 操作 | 方法 |
|------|------|
| **移动位置** | 拖动色块中心 |
| **缩放大小的** | 拖动色块边缘控制点 |
| **添加引线标注** | 启用引线标注后自动显示 |
| **拖动引线起点** | 拖动紫色圆点调整起点 |
| **拖动标签** | 拖动标签文字移动位置 |
| **查看详情** | 双击色块 |
| **右键菜单** | 右键 → 删除色块/详情 |

### 引线标注功能

```
1. 启用引线标注：
   - 添加/编辑物品时开启 "显示引线标注" 选项

2. 拖动引线起点：
   - 点击并拖动色块边缘的紫色圆点
   - 圆点可移动到色块边界任意位置

3. 拖动标签文字：
   - 拖动标签到任意位置
   - L型折线自动跟随更新

4. 位置保存：
   - 所有位置调整自动保存
   - 刷新页面后保持不变
```

### 管理图层

```
添加层：
1. 点击右侧层列表底部的 "+ 添加层"
2. 输入层名称
3. 点击 "添加"

跨层移动：
1. 拖拽色块到目标层标签
2. 松开鼠标完成移动

删除层：
1. 右键点击层标签
2. 选择 "删除"（该层必须无物品）
```

### 管理视图

```
添加视图：
1. 点击标签页导航末尾的 "+ 添加视图"
2. 输入视图名称和尺寸
3. 点击 "添加"

重命名/调整尺寸：
1. 右键点击视图标签
2. 选择 "重命名" 或 "调整尺寸"
```

### 导出/导入备份

```
导出：
1. 点击顶部 "导出备份" 按钮
2. 自动下载 JSON 文件

导入：
1. 点击顶部 "导入备份" 按钮
2. 选择 JSON 文件
3. 确认后自动刷新恢复
```

## 🛠️ 技术架构

### 双模式设计

```
┌─────────────────────────────────────────┐
│              应用层 (Browser)             │
│  ┌─────────────────────────────────────┐ │
│  │         Storage 模块（统一接口）        │ │
│  │    自动检测后端可用性，智能切换模式     │ │
│  └─────────────────────────────────────┘ │

│              ↓              ↓             │
```

## ❓ 常见问题

### Q1: 端口被占用？

```python
# 编辑 start_server.py
PORT = 8000  # 改成 8080 或其他端口
```

### Q2: 色块不显示？

```
1. 检查物品是否已添加色块
2. 切换到正确的视图和层
3. 刷新页面（F5）
```

### Q3: 数据丢失？

```
1. 找到最近导出的备份文件
2. 点击 "导入备份"
3. 选择备份文件恢复
```

### Q4: 引线标注不显示？

```
1. 编辑物品，确认开启 "显示引线标注"
2. 刷新页面（F5）
3. 检查控制台是否有报错（F12）
```
