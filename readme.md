# 📦 个人物品管理系统

> **Inventory Management System | 可视化版本 v1.0**  
> **开发者：陈懿灵**

## ✨ 功能特性

### 🎯 核心功能

| 功能 | 说明 |
|------|------|
| **可视化色块** | 用色块直观展示物品在视图中的位置 |
| **拖拽移动** | 拖动色块中心即可移动物品位置 |
| **自由缩放** | 拖动色块边缘可调整色块大小 |
| **多层管理** | 每个视图支持多个层，分类存放物品 |
| **11+ 个视图** | 床铺/书桌/衣柜/书架等独立视图，支持自定义添加 |
| **18+ 个分类** | 电子类/书籍类/衣物类等，支持自定义增删改 |
| **搜索筛选** | 按名称/分类/状态快速查找物品 |
| **借用管理** | 记录物品借用信息，追踪归还状态 |
| **数据备份** | 导出/导入 JSON 备份文件，完整包含色块信息 |
| **批量导入** | 支持 CSV 格式批量导入物品 |

## 📖 使用说明

### 1️⃣ 添加物品

```
1. 点击顶部"+ 添加物品"按钮
2. 填写物品信息（名称/分类/状态/视图/层）
3. 点击"保存物品"
4. 询问是否添加色块 → 选择"是"
```

### 2️⃣ 添加色块

```
1. 点击物品清单中的"添加色块"按钮
2. 选择形状（长方形/正方形/圆形/不规则）
3. 选择颜色（自动匹配分类颜色）
4. 点击"确认"
5. 色块出现在视图中心
6. 拖拽到目标位置，拖动边缘缩放
```

### 3️⃣ 操作色块

| 操作 | 方法 |
|------|------|
| **移动位置** | 拖动色块中心 |
| **缩放大小** | 拖动色块边缘控制点 |
| **查看详情** | 双击色块 |
| **右键菜单** | 右键点击色块 → 删除色块/详情 |
| **跨层移动** | 拖拽色块到右侧层标签 |

### 4️⃣ 管理图层

```
添加层：
1. 点击右侧层列表底部的"+ 添加层"
2. 输入层名称
3. 点击"添加"

删除层：
1. 右键点击层标签
2. 选择"删除"（该层必须无物品）

重命名层：
1. 右键点击层标签
2. 选择"重命名"
3. 输入新名称
```

### 5️⃣ 管理视图

```
添加视图：
1. 点击标签页导航末尾的"+ 添加视图"
2. 输入视图名称和尺寸
3. 点击"添加"

重命名视图：
1. 右键点击视图标签
2. 选择"重命名"
3. 输入新名称

调整视图尺寸：
1. 右键点击视图标签
2. 选择"调整尺寸"
3. 输入新的宽高值

⚠️ 注意：视图不支持删除（保护数据安全）
```

### 6️⃣ 管理分类

```
打开分类管理：
1. 点击顶部"配置管理"按钮
2. 进入分类管理界面

添加分类：
1. 输入新分类名称
2. 点击"添加"

重命名分类：
1. 点击分类的"重命名"按钮
2. 输入新名称
3. 自动更新所有该分类的物品

删除分类：
1. 点击分类的"删除"按钮
2. ⚠️ 该分类下不能有物品
```

### 7️⃣ 搜索筛选

```
搜索框：输入物品名称/简介/备注关键词
分类筛选：选择特定分类
状态筛选：在位/带走/借出
```

### 8️⃣ 借用管理

```
记录借用：
1. 点击物品清单中的"借用"按钮
2. 填写借用人/日期/预计归还日期
3. 点击"确认借用"

归还物品：
1. 点击顶部"借用清单"
2. 找到对应记录
3. 点击"归还"
```

### 9️⃣ 批量导入

```
1. 准备 CSV 文件（UTF-8 编码）
2. 格式：名称，分类，状态，视图，层，简介，备注
3. 点击顶部"批量导入"按钮
4. 选择 CSV 文件
5. 等待导入完成，页面自动刷新
```

## 💾 数据管理

### 导出数据

```
1. 点击顶部"导出备份"按钮
2. 浏览器自动下载 JSON 文件
3. 建议每周导出一次，保存到安全位置
```

### 导入数据

```
1. 点击顶部"导入备份"按钮
2. 选择之前导出的 JSON 文件
3. 确认后页面自动刷新
4. 数据恢复完成
```

### 备份包含的数据

| 数据类型 | 是否包含 | 说明 |
|----------|----------|------|
| 物品信息 | ✅ 是 | 名称/分类/状态/简介/备注 |
| 色块信息 | ✅ 是 | 形状/颜色/大小/位置 |
| 视图配置 | ✅ 是 | 视图 ID/名称/尺寸 |
| 分类配置 | ✅ 是 | 分类列表 |
| 层配置 | ✅ 是 | 层 ID/名称/视图关联 |
| 借用记录 | ✅ 是 | 借用人/日期/归还状态 |

### 数据存储位置

```
存储方式：浏览器 localStorage
存储位置：当前浏览器的本地存储
数据键名：
  - inventory_items      (物品数据)
  - inventory_layers     (层数据)
  - inventory_borrows    (借用记录)
  - inventory_views      (视图配置)
  - inventory_categories (分类配置)
```

⚠️ **重要提示：**
- 清空浏览器缓存会丢失数据
- 换浏览器需要重新导入备份
- 建议定期导出备份到 U 盘/网盘

## ❓ 常见问题

### Q1: 端口被占用怎么办？

```python
# 编辑 start_server.py，修改 PORT 值
PORT = 8000  # 改成 8080 或其他端口
```

### Q2: 色块不显示怎么办？

```
1. 检查物品是否已添加色块（清单中显示📍标记）
2. 切换到正确的视图和层
3. 刷新页面（F5）
4. 检查控制台是否有报错（F12）
```

### Q3: 数据丢失了怎么办？

```
1. 找到最近一次导出的备份文件
2. 点击"导入备份"
3. 选择备份文件
4. 数据恢复完成
```

### Q4: 如何在多台电脑同步？

```
方案 1：手动同步
  1. 在电脑 A 导出备份
  2. 复制备份文件到电脑 B
  3. 在电脑 B 导入备份

方案 2：U 盘携带
  1. 整个项目文件夹放 U 盘
  2. 在任何电脑运行 start_server.py
  3. 数据随 U 盘携带
```

### Q5: 删除层时提示"该层还有物品"

```
1. 先将该层的物品移动到其他层
   - 拖拽色块到目标层标签
2. 或者删除这些物品
3. 然后再删除层
```

### Q6: 分类下拉框不显示新分类

```
1. 确保在"配置管理"中添加了分类
2. 关闭配置管理弹窗
3. 刷新页面或重新打开添加物品弹窗
4. 分类应自动同步到所有下拉框
```

### Q7: 添加色块按钮没反应

```
1. 按 F12 打开控制台查看错误
2. 检查 CATEGORY_COLORS 是否定义
3. 确保 data.js 在 crud.js 之前加载
4. 刷新页面（Ctrl + F5 强制刷新）
```
